# Kiln UI

**A shadcn registry of ready-to-use components and animations.**

<br/>

Kiln UI is a Shadcn registry built with Next.js, Tailwind CSS, and TypeScript. Every component comes with smooth Motion animations, respects `prefers-reduced-motion`, and drops directly into your codebase. No packages to install, no lock-in—just fully customizable components you own.
